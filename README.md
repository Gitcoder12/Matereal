# Matereal

Material selector platform for engineers and designers. Compare properties, applications, and sourcing for 10+ real materials.

## Features
- Material property comparison (density, tensile strength, thermal conductivity)
- Application use-cases per material
- Supplier info and pricing estimates
- Dark academic UI, responsive

## Stack
React 18 (CDN), Crimson Pro / Work Sans fonts. Single page, GitHub Pages deployable.
